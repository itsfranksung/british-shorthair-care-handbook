# 英國短毛貓養育教學書

以你們實際養的英國短毛貓為主角，將日常照顧整理成能真正翻動的互動教學書。

## 內容

- 闔上的書與自家英短動畫化角色入場
- 使用者自行點擊、滑動或用方向鍵翻頁
- 定量餵食、體重、飲水砂盆、陪玩、梳毛與身體語言
- 家電家具防護、每月預算、HCM／PKD 與就醫警訊
- 可勾選的日常清單與本機進度保存
- 兩枚可再次點擊取消的互動爪印
- 手機與桌面版響應式閱讀

## 本機執行

```bash
npm ci
npm run dev
```

## 建置

```bash
npm run build
```

推送到 `main` 後，GitHub Actions 會自動部署至 GitHub Pages。
